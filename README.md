# Signal Optimizer 🚦

## Description
This project simulates traffic flow at junctions and optimizes signal timings
based on vehicle count using Basic and Adaptive optimization strategies.

## Features
- Load junction configuration
- Simulate traffic
- Optimize signal timings
- Export signal plan report

## Technologies Used
- Java
- OOP Concepts
- Collections
- File Handling

## How to Run
1. Clone the repository
2. Compile Java files
3. Run MainApp
4. Provide junction.cfg input

## Sample Input (junction.cfg)
J1,4,10
J2,3,15

## Output
Green signal time per lane
